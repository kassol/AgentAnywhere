# Craft 组件迁移

## 职责

本目录保存从 Craft Agents OSS v0.13.3（commit `e8963854c3679edcceb105a42537a06749e6cb64`）迁入的前端组件，以及为 AgentAnywhere 现有接口所做的最小适配。

## 目录结构

- `components/`：输入、轮次、工具活动和报告阅读组件。
- `lib/`：迁入组件共享的纯前端工具。
- `styles.css`：Craft 组件使用的 Tailwind 主题映射与局部样式。

## 模块规范

- 每个迁入文件保留上游版本、原路径、版权和许可证说明。
- 保留使用中的原函数和 JSX 结构。裁剪 Electron、附件、批注、模型选择等无关产品功能时，在文件头记录差异。
- 组件只接收现有页面传入的数据和回调。不得在本目录新增业务 API、数据库字段或并行状态机。
- 使用相对 import。公共组件从原组件名文件导出。
- 富文本输入保持纯文本提交、粘贴转义、撤销、光标、IME 和长度上限行为。发送成功后的草稿清理由现有 Composer 状态机决定。

## 依赖关系

本目录可依赖 React、Tailwind、Motion、Lucide 及通用 UI 工具。业务页面通过 props 提供安全 Markdown 渲染器和现有领域数据。
