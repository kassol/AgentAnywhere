# 首个可用版本：精简 Web 与模型接入

日期：2026-09-18。状态：grill-with-docs 访谈中，逐项决定已记录，等待整体确认；尚未形成实现 spec 或授权开始实现。完整产品范围仍以 PRD/MVP 为准，本文件限定首个可用增量。

## 已确认的验收路径

配置模型连接与搜索服务 → 新建调研工作 → 查看流式消息和工具活动 → 必要时追加要求或回答问题 → 阅读/下载带来源的报告 → 沙箱回收后仍可读取报告 → 原工作追加要求后产生新的报告版本。

## 逐项决定

| 问题 | 决定 |
| --- | --- |
| Q1 验收边界 | 单任务成果闭环；管家委派后续扩展 |
| Q2 任务样例 | 公开资料调研，带来源的 Markdown 报告 |
| Q3 工作入口 | 工作列表、新建工作、工作对话，另有模型设置入口 |
| Q4 资料入口 | 同时接受主题搜索与用户指定公开链接 |
| Q5 执行中交互 | 追加要求、Agent 提问等待回答、取消 |
| Q6 模型连接 | 一套 sub2api 端点与凭证，多个可选模型 |
| Q7 追加时机 | 当前工具结束后、下一个模型步骤前生效，显示待处理状态并保留已有资料 |
| Q8 完成后补充 | 同一 Task/工作对话中新建 Run，保留旧报告并产生新版本 |
| Q9 元信息缺失 | 允许人工补充，核查 models.dev 作为自动补全来源 |
| Q10 等待回答 | 保存进度与必要文件后释放沙箱；回答后重建，不保留内存进程 |
| Q11 并发 | 单项执行、其余排队；等待用户回答释放执行名额 |
| Q12 成果 | 在线阅读、历史版本、Markdown 下载；其他产出按附件保存 |
| Q13 元信息优先级 | 人工覆盖 → 网关信息 → 明确匹配的 models.dev → 未知；逐字段保留来源，别名显式映射 |
| Q14 搜索服务 | 接受独立搜索服务和独立 API Key；具体服务待核查后确认 |
| Q15 协议 | 每模型保存默认协议，新工作默认只选模型，高级选项可覆盖；Chat Completions/Responses 均须验收 |
| Q16 持续故障 | 短暂网络错误有限重试；持续失败或服务重启中断后保留进度，用户在原工作中发起新 Run 重试 |
| Q17 上限 | 每 Run 45 分钟活跃时长、40 轮模型调用；等待回答不计活跃时长，到达上限保存并等待继续决定 |

## 复用与事实边界

W0 原生 Craft 页面继续作为独立验证环境。正式 Web 按本文件的工作入口组织，抽取消息、工具卡、输入框、预览和样式；完整产品菜单不会因上游存在而自动引入。Electron、公开分享、无关渠道、订阅登录及无关后端路径按 MVP 第 3 节裁剪。用户登录保护和已有安全边界继续适用。

锁定 Craft `e8963854c3679edcceb105a42537a06749e6cb64` 的核查结果：

- `packages/server-core/src/model-fetchers/index.ts:76` 对自定义兼容端点直接跳过模型发现。
- `packages/pi-agent-server/src/custom-endpoint-models.ts:69` 使用默认能力、限制及零价格；它们不能作为真实网关能力或账单的证据。
- `packages/pi-agent-server/src/index.ts:483` 将自定义协议交给 Pi registry；现有界面与配置校验仍需扩展 Responses，全链路仍待验收。
- `packages/pi-agent-server/src/tools/search/resolve-provider.ts:62` 的 OpenAI 搜索固定使用官方 API；不可直接将 sub2api 凭证沿用到该路径。首版搜索凭证独立。

[models.dev 官方 Schema](https://github.com/anomalyco/models.dev/blob/dev/packages/core/src/schema.ts) 包含限制、模态、工具、推理及供应商价格等信息，可用于明确身份匹配后的补全。目录能力与网关实测能力分别标记，参考价格不作为 sub2api 实际账单。来源接口、更新时间与缓存状态需可追溯。调研工具访问公开 JSON 返回 403；cc-la 上的实际获取能力尚未验证，不能声明接口已接通。

## 搜索候选核查（尚未确认）

建议 Tavily Basic，使用直接 HTTP Search API 获取来源列表，正文单独读取。官方在 2026-09-18 的[价格说明](https://docs.tavily.com/documentation/api-credits)列明每月 1000 免费 credits、Basic 每次 1 credit，按量计费为 $0.008/credit；[接口](https://docs.tavily.com/documentation/api-reference/endpoint/search)支持返回标题、URL、摘要和时间过滤。中文质量及 cc-la 可达性尚待实测。建议关闭自动升级搜索深度，不代为注册、开通付费或提交凭证；应用不能保证外部账号已配置的计费策略，额度边界须结合服务响应与实际账号核查。
