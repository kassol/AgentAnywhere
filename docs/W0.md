# W0 基线验证：决策记录

状态：执行方案已确认，进入 W0 分项验证。本文记录验证范围、执行约束与证据。

依据：[MVP 的开发任务包](MVP.md#13-开发任务包与依赖)。

## 已确认

- 分项验证原生 Craft WebUI 与 Pi/sub2api 的模型工具调用、OpenSandbox 生命周期、浏览器人工接管与隔离运行时兼容性；交付可复现证据及阻塞项。
- Craft 固定版本在独立检出目录验证；主仓库保存必要探针与结果，随后按依赖提取模块。
- 在指定 Linux VPS `cc-la` 验证，已完成 SSH 只读核查；按下述范围新增独立验证资源。
- 模型验证前由所有者在 WebUI 手动配置 sub2api provider 与模型，凭证明文不进入仓库或 Issue。
- WebUI 与接管服务监听宿主机 `127.0.0.1`；提供端口后由所有者配置现有 1Panel/OpenResty 反向代理并提供访问地址。入口需要登录保护。
- gVisor 无法运行浏览器时保留阻塞，记录证据后重新决定执行环境；相应验证项保持未通过。

## 已确认执行方案

- 在 `cc-la` 的 `/opt/agentanywhere-w0` 使用独立目录、容器、网络与数据卷；创建前检查路径和端口占用。Craft 固定源码另行检出，测试工具限定在容器内执行。
- 仅新增 W0 所需资源；保留现有服务、数据库与反向代理配置。安装 gVisor 前核查安装步骤与 Docker runtime 注册方式；涉及共享 Docker 重启或影响现有服务的变更先作为阻塞报告。
- 优先验证 Craft 已有登录机制，确保未登录访问 WebUI/API/实时连接被拒；浏览器接管页面及其 WebSocket 同样受鉴权保护。登录保护通过后交付反代端口，再由所有者配置 provider 与模型。
- Craft/Pi：保留锁定版本，验证原生 WebUI 构建与启动、真实模型流式输出、一次无外部写入的工具调用、取消与用量展示。
- OpenSandbox：固定版本，验证创建、执行命令、文件读写、状态查询与销毁，确认资源确实回收。
- Browser：固定匹配版本的 Chromium/Playwright 与显示服务，在 gVisor 下验证非 root 启动、公开测试页面操作、截图/下载，以及 noVNC 对同一浏览器实例的接管。记录浏览器自身 sandbox 配置与容器隔离配置。
- 保存版本清单、可重复执行的探针、脱敏日志、截图与逐项通过/失败/阻塞结果；成果复制出沙箱后验证可读取。W0 分项通过不代表正式 Broker 控制租约或完整安全验收已完成。
- 验证结束后清理本轮临时容器、网络与测试数据，保留复现脚本和证据；需继续人工验证的环境保持为未完成事项，验证后再清理。
