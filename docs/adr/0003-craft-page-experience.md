# ADR-0003：页面体验以 Craft 为优先基准

- 日期：2026-09-20
- 状态：已采纳；共同理解已确认，下一阶段为全页面原型。

R4 已完成原组件迁移，产品所有者仍认为整体体验与 Craft 存在明显差距。下一轮允许重新组织导航、列表、对话与报告面板，以 Craft 页面体验为优先基准，保留现有业务能力；最终布局通过可运行原型确认。

本决定替代 ADR-0002 中保留 A 侧栏与面板布局的约束。原组件来源、已确认字体及业务数据身份继续沿用既有决定；具体页面方案须经原型确认后进入实施。

日常使用以管家对话为主线，工作列表与待办保留可直达入口。允许为明确的展示需求补充字段或接口，工作执行、授权、不可变版本和恢复语义继续保持。

默认信息以结果和介入为先：展示短标题、当前进度、成果与待回答事项；工具参数、完整 ID 和操作回执置于可展开详情，精确操作仍使用原身份。同一对话的多项工作各有一个集中入口，历史执行展开查看，对话保留关键事件。

对话和工作采用自动生成、用户可修改的显示标题，允许必要模型调用；原始要求完整保留。标题只承担展示职责，不改变工作目标或身份。

进入规格前建立全页面可运行原型：委托、执行、介入、报告阅读与改稿主流程具备交互，工作、待办、设置、登录、浅深主题和小屏共同形成页面基准。原型采用固定 Craft 基线与已迁入原组件，使用真实内容样本和明确标识的模拟状态；产品所有者确认后再转规格和票据。原型用于确认页面体验，真实业务与发布验收仍在实现阶段完成。

自动命名失败时回退到原文摘要，后到的自动结果保留用户已修改的标题。原型覆盖长内容、多项工作、等待回答、失败与多版本报告，面板比例、间距和展开方式通过页面比较确定。

验收同时核查组件来源、用户可观察行为和已确认页面基准。正式实现使用可比较视口与内容逐页核对原型；功能测试通过、没有横向溢出本身不足以证明页面体验达标。
