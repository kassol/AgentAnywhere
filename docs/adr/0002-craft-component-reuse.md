# ADR-0002：当前阶段优先迁移 Craft 原组件

- 日期：2026-09-20
- 状态：已采纳；迁移尚未实施，技术范围待源码核查与运行验证

现有界面主要通过本地实现参考 Craft 的样式和交互，尚未完成以原组件为主体的复用。为避免继续扩展本地组件后增加迁移成本，将实际代码复用提前为当前优先事项，覆盖管家、工作、待办、报告和设置全部现有页面中的适用组件。

有对应 Craft 组件时，以其原源码为基础适配；无法复用的部分必须记录源码依据、平台依赖和替代方案，由产品所有者确认例外，不能由实现者仅按成本自行改为重写。保留已确认 A 方案的侧栏与面板布局及字体决定；局部外观或交互冲突时优先沿用 Craft 原组件，接受 A 局部细节调整，以减少长期维护差异。

本决定收紧后续实现的复用标准，不表示历史 R3 已满足该标准。迁移组件清单、依赖方案和验收条件在后续规格中明确；现有业务专用界面是否存在适用上游组件须逐项核查，不能承诺所有 UI 均来自 Craft。

允许引入源码核查后确认必需的 UI 依赖，继续使用现有业务 API、能力与数据，不引入 Electron 运行时或无关产品功能。依赖清单由实际组件需要决定，不以维持零新增依赖为迁移约束。

共同理解已确认。下一阶段恢复固定 Craft 提交的只读源码，建立逐组件对照，并以“输入 → 消息与工具展示 → 打开报告”可运行链路验证依赖和数据适配，再形成完整规格与票据。最终验收同时核查源码来源、适配差异、行为回归及 ego-browser 的真实视觉与交互；仅有外观相似或功能测试通过不足以证明完成迁移。
