# ADR-0001：公开仓库与工程工作流

- 日期：2026-09-18
- 状态：已采纳

## 背景

项目已有 PRD、MVP 与架构材料，需要持久化任务、领域定义与关键决策，支持跨会话实施。

## 决定

- 使用独立公开仓库 `kassol/AgentAnywhere`，保留现有 Git 历史。
- 使用 GitHub Issues 管理任务与 spec；依赖使用原生阻塞关系。
- 根目录 `AGENTS.md` 作为工程规范入口，`docs/agents/` 保存技能配置。
- 根目录 `CONTEXT.md` 保存单一领域定义，`docs/adr/` 保存关键决策。
- 使用五个默认 triage 标签，具体映射见 [标签配置](../agents/triage-labels.md)。

## 影响

任务与决策可以跨会话追踪。工程技能产物完成后提交并推送。应用技术基线仍需按 MVP 的 W0 验证；本次配置不表示应用已实现。
