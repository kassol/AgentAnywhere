# R2-01 管家模型与人工调研模型池

对应 [Issue #19](https://github.com/kassol/AgentAnywhere/issues/19)。本票交付配置与服务端资格检查，管家执行和真实调研验证记录由后续任务接入。

- API：在独立 PostgreSQL 上验证模型配置保存、重开、非法候选拒绝及 R1 工作创建兼容。网关列表遗漏的手填模型保留尝试资格；仅支持图片的模型不能用于文本调研。配置与工作公开 API 测试缺少数据库时明确失败，并接入统一隔离入口。
- 浏览器：ego-browser TaskSpace 32，隔离页面 `http://127.0.0.1:19116`。键盘登录后，手填模型与必要参数，保存默认 Chat Completions、管家 Responses 及人工池；刷新后配置保留，密钥字段为空。键盘 Space 撤销入池并保存，刷新后显示空池提示；重新勾选和保存成功。
- 视觉：已检查[设置页截图](r2-01-settings.png)，协议、池勾选及验证状态可读，控件未溢出。页面如实标注实际调研尚未核验，连接测试不等于工具能力验证。
- 类型检查、构建及真实数据库的模型配置/工作目标回归通过。完整隔离执行、真实模型和公网发布验证在 R2-12 完成。

测试使用独立配置与测试凭证，未修改正式站点模型设置或用户工作。
