## 核心视觉修复

首次真实轮次截图显示 TurnCard 折叠按钮带浏览器原生灰底和立体边框。根因是 `src/web/craft/styles.css` 为保护 A 外壳只导入 Tailwind theme/utilities，没有导入上游依赖的 preflight；TurnCard 上游原生 `<button>` 自身只有布局、hover 和焦点 utility，默认背景与边框由 preflight 清除。

`src/web/craft/components/TurnCard.tsx` 现为该原生按钮标记 `data-craft-button`，`src/web/craft/styles.css` 在组件层补齐上游依赖的 `appearance/margin/border/background/font/color` reset；utility 层继续决定 padding、圆角、hover 和焦点。`src/web/style.css` 同时把该按钮排除出 A 的全局焦点 outline，保留原 TurnCard `focus-visible:ring`。

同轮 computed style 还显示所有 `.shadow-middle` / `.shadow-minimal` 表面的 `box-shadow: none`。生成规则没有被旧全局 CSS 覆盖；根因是 `--foreground-rgb` 延续 A 的逗号分隔值 `38, 36, 42`，迁入的 `rgb(var(--foreground-rgb) / 7%)` 展开后为无效颜色，使整条多重 `box-shadow` 失效。局部 Tailwind token 已改为兼容该现有变量格式的 `rgba(var(--foreground-rgb), .07)`；ResponseCard 和 FreeFormInput 继续使用原 `bg-background`、`shadow-minimal`、`shadow-middle`，无需提高阴影或改色。
