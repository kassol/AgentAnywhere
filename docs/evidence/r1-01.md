## 来源与裁剪

- Craft Agents OSS v0.13.3，提交 `e8963854c3679edcceb105a42537a06749e6cb64`，Apache-2.0。版权归 Craft Docs Ltd.，许可文本见 `licenses/CRAFT-APACHE-2.0.txt`。
- `src/web/EmptyStateCard.tsx` 改写自 `packages/ui/src/components/ui/BrowserEmptyStateCard.tsx`：仅保留标题与描述，删除浏览器示例、i18n 和无用交互。
- `src/web/style.css` 采用 `apps/electron/src/renderer/index.css` 的浅色背景、紫色强调色及空状态容器视觉；登录卡参考 `apps/webui/src/login.html`。全部样式改成独立 CSS。

- 检查上游 `BrowserEmptyStateCard.tsx`、`UserMessageBubble.tsx`、`SystemMessage.tsx`、`apps/webui/src/App.tsx` 及各自 import。消息、工具卡、输入和预览依赖 `@craft-agent/core`、`@craft-agent/shared`、Markdown、i18n、桌面平台适配及更多组件；#4 无工作对话，暂不抽取。后续在对应交互真实接入时逐个核查并提取。
- 当前直接运行依赖仅 React 与 React DOM；构建依赖为 Vite、TypeScript 和类型声明。`package.json` 和 `bun.lock` 均无 Electron。Docker 构建仅安装本仓库依赖。

## 启动与验证

```sh
bun install --frozen-lockfile
bun run build
bun run typecheck
bun test
AGENTANYWHERE_PASSWORD='本机专用的至少十二位密码' bun run start
```

服务默认只监听 `127.0.0.1:3000`。容器内设 `AGENTANYWHERE_HOST=0.0.0.0`。HTTPS 反向代理时设 `AGENTANYWHERE_SECURE_COOKIE=true` 和 `AGENTANYWHERE_PUBLIC_ORIGIN=https://实际域名`；密码仅放部署主机的私有环境文件，不写仓库。会话在进程重启后失效，持久登录密码由部署环境保存。

本地验证：`bun run build`、`bun run typecheck`、`bun test src/server.test.ts` 通过。HTTP/WebSocket 黑盒检查覆盖匿名页面重定向、API 和实时连接拒绝、错密、成功登录、Cookie 标志、空工作列表、设置、退出后旧 Cookie 及实时连接拒绝、跨来源和超长登录请求。主线程通过 ego-browser TaskSpace 31 在 `http://127.0.0.1:19110` 验证匿名跳转、中文错误、键盘登录、空工作列表、刷新保留会话、设置和键盘退出；截图在 `/tmp/agentanywhere-r1-workbench.png`。这些是本地 #4 证据；部署环境、模型、队列、沙箱与报告由后续票验收。

Bun 1.3.10 容器从固定锁文件构建成功；本地容器匿名页面返回 302 `/login`、匿名 `/api/tasks` 返回 401。

代理跳转回归：在 `AGENTANYWHERE_PUBLIC_ORIGIN=https://agent.example`、Secure Cookie 和代理请求头下，匿名访问 `/` 返回相对 `Location: /login`，登录后访问 `/login` 返回相对 `Location: /`；浏览器沿原 HTTPS 来源跳转，不产生 HTTP 降级。
