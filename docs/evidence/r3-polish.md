## 修正

- 基础排版恢复 14px / 1.45；侧栏 252px、标题省略、消息头像及工具卡密度、760px 输入区与底栏回到 A 的约束。长对话独立滚动，输入保持在底部。

- Inter 4.1 自托管，可变字重和许可随代码保存；中文使用系统中文字体。固定 Craft 默认使用系统字体，Inter 为其可选项，来源事实见 [提取记录](../r3-craft-source.md)。

## 根因与复核

首轮真实截图进一步发现共享 CSS 在组件 CSS 之后加载，覆盖工作行与表单的专用规则；预览容器缺少完整宽高约束，导致输入区缩窄或溢出到底部之外。入口调整为基础 CSS 先加载，再加载组件样式，并补齐预览与对话容器的高度链。桌面测量：输入宽 760px，1440×900 下底边为 884px，三个不同长度工作状态的横坐标均为 1247px。

正式首轮部署还发现 CSP 未声明 `font-src`，使已发布字体被 `default-src 'none'` 拒绝。补充 `font-src 'self'`，保留其他安全限制；公网回归新增同源字体策略、CSS 字体引用、字体 GET 及 WOFF2 文件头断言。开发页面的字体加载成功不能代替正式 CSP 验证。
