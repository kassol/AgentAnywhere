# R2-02 持久管家对话与有界轮次

对应 [Issue #20](https://github.com/kassol/AgentAnywhere/issues/20)。管家首页提供独立对话、双协议流式回复和全局单轮调度，原工作与设置入口保留。

- 公开 API 与真实 PostgreSQL：`src/steward.test.ts` 验证认证、并发创建幂等、双协议、跨对话排队、同对话三轮上下文顺序、排队撤回、执行中停止、服务重启中断及显式继续。注入时钟验证 300000 毫秒边界，达到上限前不发送模型请求。配置清空后重试原请求仍返回同一轮次，改内容返回冲突。4 项测试、40 个断言通过。
- 生命周期：服务停止等待管家后台写入结束；流式文本按增量串行持久化；轮次固定模型和凭证版本。实际 HTTP 尝试在服务端计数。
- ego-browser：TaskSpace 32、隔离入口 `http://127.0.0.1:19116`。完成 Chat Completions 对话后刷新，消息保留；流式处理中刷新，已生成文本保留；另一对话排队并撤回；停止运行轮次后切换 Responses，显式发送下一条消息并完成。普通对话后工作列表仍为空。原工作创建页与设置入口可访问。
- 视觉：检查[管家对话截图](r2-02-steward.png)，中文状态、保留的部分回复和新轮次可见，无控件溢出。
- 构建、类型检查、差异空白检查通过；Bun 1.3.10 Web 镜像构建通过。测试已接入统一隔离入口。

本票尚无工具往返，单轮最多首次请求及一次网络重试，8 次调用边界由后续工具链回归补齐。完整回归、真实工具链及正式发布由 R2-12 统一验收。本机曾执行的全仓回归有一次 PostgreSQL 连接数耗尽失败，不能计作全套通过。
