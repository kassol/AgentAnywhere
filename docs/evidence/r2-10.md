# R2-10：按持久回执继续操作

实现与本地回归已完成；统一隔离故障矩阵及真实浏览器复验待完成，Issue #28 保持开放。

## 行为

六类操作分别接收完整“继续调研/追加/取消/回答/重试/改稿回执 UUID”命令。页面按钮只填入命令，发送后才创建独立新轮次。已接受操作读取原结果；未执行操作保持原业务身份，并重新核对当前模型池、凭证及工作状态。目标尚未冻结的操作要求重新委托。

回答由服务端从完整用户消息直接解析，避免模型重复转写导致有效回答被拒。控制与调研增加当前消息的正向委托校验，防止引用或否定文本误授权。指定 UUID 的控制、回答、重试和改稿要求目标一致；自然语言控制目标必须唯一匹配。

等待态追加等业务拒绝保留实际失败原因。重试回执兼容历史 JSON 字符串快照，只公开模型 ID 和协议。
