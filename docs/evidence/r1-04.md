# R1-04 工作创建与待执行请求

所有者可在工作页填写目标或公开链接，选已配置模型，并在高级选项中覆盖协议。`POST /api/tasks` 使用客户端 `requestId` 去重；创建一个 Task、一个工作 Thread、初始用户消息和一个待执行 Run。工作列表与详情均从 PostgreSQL 读取，刷新或服务重启后可恢复。

Run 的模型快照来自模型连接的可见有效配置，包含模型、协议、端点及已知运行参数和来源字段。快照不含明文凭证。当前凭证由 ModelConnection 单独保管；旧 Run 的凭证版本绑定尚未完成，执行接入时须处理，不能用修改后的凭证暗中请求旧端点。

本票使用 Bun SQL 连接 `DATABASE_URL`，启动时建立 `work_tasks`、`work_threads`、`work_runs`、`work_messages` 四张表。工作目前只进入 `queued`，界面显示“待执行”；Worker、队列消费、模型调用、实时输出与后续状态流转均待后续票验证。

本地公开 API 回归使用独立 PostgreSQL，验证了鉴权、跨域拒绝、参数错误、目标与仅链接创建、重复请求去重、详情和列表、服务重启恢复，以及模型设置修改后旧 Run 快照不变。真实浏览器端到端验收由集成阶段统一执行。
