## Spec

主会话另确认版本预检存在异步覆盖新输入的风险，`d95f19e` 仅附加原提交身份并保留最新草稿。新选区替换未保存意见也经过确认，小屏汇总成功后返回聊天框。

快捷命令只携带 Task 时，草稿停留期间可能被新问题或新 Run 替代。`7405e17` 将 Interaction/Run 身份写入快捷命令，服务端核对原文并在既有冻结事务内校验目标；旧手输命令继续兼容。真实 PostgreSQL 聚焦回归验证旧问题保持隔离、旧 Run 控制/重试被拒绝，以及新语法接受后的回执恢复。主会话复核了解析、请求哈希、冻结锁行和恢复调用链。

Standards 三项、Spec 五组问题均已有对应修复；主会话追加发现的异步覆盖与键盘选区焦点问题也已修复。`7299d05` 另修复版本切换时读取旧 DOM ref 的定位误判，浏览器往返复核通过。最终截图发现的工作列表、批注主按钮和报告主题样式遗漏已由 `3e85eaa`、`4aa162c` 修复；最终 `1d4d8a2` 已通过正式发布与浏览器复核，见 [整体验收](r3-08.md)。

轮询期间内联 Markdown renderer 曾导致链接重新挂载和焦点丢失。`dd8de89` 固定组件引用，`ca462ce` 保留可运行身份回归；隔离报告与正式对话链接经两次真实轮询仍保持节点和焦点。
