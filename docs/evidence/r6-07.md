## 部署修复记录

| 问题 | 根因 | 修复 |
|------|------|------|
| Dockerfile 缺少新增 .mjs 模块 | 子 agent 只改了源码没改 Dockerfile | 补充 COPY 指令 |
| compose.yaml 缺少 AGENT_CODING_IMAGE | 新增环境变量未加入 compose | 补充到 environment 块 |
| deploy.sh 未校验 agent-coding 镜像 | 新镜像未加入校验列表 | 补充到 for 循环 |
| 委派正则不接受"编码任务" | `explicitResearchDelegation` 只匹配"调研" | 扩展正则支持"编码" |
| 委派正则不接受"一个编码任务" | 量词后的名词组必须是"主题/问题/方向/目标" | 让名词组可选 |
| queue 容器无 git | Node.js 基础镜像不含 git | Dockerfile.queue 安装 git |
| git clone SSL 失败 | 容器缺少 CA 证书 | 安装 ca-certificates |
| 文件 mode 格式错误 | OpenSandbox SDK 不接受 JS octal 数字 | 改用十进制三位数（644/755） |
| sandbox 重连后仍 "not connected" | inject catch 路径执行 cleanup 销毁沙箱后 finally 又尝试读取 | 改为 throw 让统一错误流程处理 |
| tmpfs 16MB 不够 clone 仓库 | 默认 tmpfs 太小 | 增大到 256MB |
| queue 无 docker logs 输出 | 无日志语句 | 添加关键路径 console.log |
