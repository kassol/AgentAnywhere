## 实现边界与服务端事实

- [批注与选择器](../../src/web/ReviewAnnotations.ts)使用 Task UUID、Version UUID、批注 UUID、固定文本偏移、原引用和意见保存本机草稿；定位失败时保留引用，不搜索相似文本，也不迁移到新版。
- [报告预览](../../src/web/WorkPreview.tsx)读取真实 Task 和 Artifact API，固定首次打开的不可变版本，并提供鼠标选区、键盘文本选择器、添加、删除和汇总入口。批注及未保存意见继续沿用原 localStorage key，没有服务端批注实体。
- [可靠输入](../../src/web/Composer.tsx)把实际仍存在于发送正文中的批注快照与请求身份一起持久化；版本预检期间的新编辑不会被旧状态覆盖。服务端接受后，[管家页面](../../src/web/Steward.tsx)按 Task、Version、批注 UUID、更新时间和实际发送正文清理本次意见。
- 发送前从公开 Task API 核对最新成功报告。发现新版时保留原版本并要求明确继续；取消不修改草稿。改稿仍调用既有服务端流程，[版本冻结与执行](../../src/work.ts)在事务中校验报告属于原 Task，固定来源版本，在原 Task 创建新 Run，并复用稳定请求与回执。
- 报告继续使用安全 Markdown 渲染。fixture 中的 script 未执行，`javascript:` 链接没有获得可用地址；引用文字本身不参与服务端授权。
