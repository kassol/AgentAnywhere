## 构建、鉴权与隔离核查

正式 Web 运行产物只含 `src` 和 `dist`，无 Electron；agent 镜像只读导出检查 25167 个条目，Electron 路径为 0，Pi 包存在。开发构建中的 `electron-to-chromium` 来自 Vite/Babel/browserslist，只是版本映射数据，无安装脚本与 Electron 二进制。Pi 上游携带其 CLI/TUI 传递依赖，应用未暴露宿主 shell。公网对 `/api/share`、`/api/channels`、`/api/subscriptions`、`/api/rpc`、`/api/oauth`、`/share`、`/desktop` 的已鉴权 GET/POST 均为 404；CSP 禁止被嵌入。

真实沙箱以非 root、gVisor 和固定资源限制运行，不挂宿主目录、Docker socket 或长期模型密钥。当前 OpenSandbox 自定义 bridge 不提供完整 networkPolicy；网络访问通过应用受控工具限制，不能据此声称任意沙箱进程具备完整网络隔离。浏览器自动化、第三方账号写入、审批与多 Agent 编排仍属规格外能力。
