# Triage 标签

| 技能角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 维护者需要评估 |
| needs-info | needs-info | 等待报告者补充信息 |
| ready-for-agent | ready-for-agent | 已明确验收条件，可由 Agent 执行 |
| ready-for-human | ready-for-human | 需要人工实施 |
| wontfix | wontfix | 已决定不处理 |

技能引用角色时使用对应标签。to-tickets 生成的可执行任务直接进入实施流程。
