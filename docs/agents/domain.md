# 领域文档

本项目采用 single-context：根目录 `CONTEXT.md` 记录领域定义，`docs/adr/` 记录关键决策。

## 读取顺序

探索、规划或实现前，读取 [CONTEXT.md](../../CONTEXT.md) 与 [docs/adr/](../adr/) 中涉及本次工作的决策。产品需求与实施验收分别见 [PRD](../PRD.md) 和 [MVP](../MVP.md)。

后续引用的领域文档尚不存在时继续工作，由 domain-modeling 在概念或决策明确后按需建立。

## 使用与维护

- Issue、代码、测试和文档使用 CONTEXT.md 定义的同一术语。
- 出现新概念时先核对已有定义，再由 domain-modeling 补充真实缺项。
- 结论与现有 ADR 冲突时，明确指出对应 ADR 和重议理由，再更新决策。
- ADR 记录背景、决定与影响，使用递增编号；已采纳的决定与待验证设计分开表述。
- 目录、公共接口、操作流程或关键约定发生长期变化时更新相关文档。
